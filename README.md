社会保険労務士（社労士）の先生方および顧問先企業向けに特化した、**ブラウザ完結型のIT端末台帳＆労務セキュリティリスク診断ツール（デモ版）**です。

---

## 🎯 開発の背景と社労士業務での役割

一般的なIT資産管理ツールは情報システム部門のスペック管理に重きが置かれていますが、**社労士実務において最もクリティカルなのは「労務管理・コンプライアンス・情報漏洩抑止」**です。

1. **退職者からの端末未回収・持ち去り防止**: 退職後もPCやスマートフォンが貸与中のまま放置されるリスクを検知。
2. **テレワーク規程・持ち出し管理の遵守**: 持ち出し許可の有無、BitLocker/FileVault暗号化、定期現物確認の徹底。
3. **情報機器貸与誓約書の回収管理**: 秘密保持・私的利用禁止・紛失時即時報告義務に関する誓約書の未提出者を抽出。
4. **顧問先への是正勧告レポート提供**: 診断結果をワンクリックでA4フォーマット（印刷/PDF出力）に出力可能。

---

## ✨ 主な機能

* **労務リスク自動診断ダッシュボード**:
  * 人事データ（社員名簿）と端末貸与台帳を自動突合。
  * 総合リスク評価ランク（A〜D）の算出。
  * 「退職者未返却」「誓約書未取得」「幽霊端末」「暗号化未設定」などをリアルタイム警告。
* **端末台帳（IT資産一覧）**:
  * PC、スマートフォン、タブレット、モバイルWi-Fiルーター等の貸与状況・セキュリティ対策状況の管理。
* **社員名簿（人事台帳）**:
  * 入退社日・雇用区分・在籍状況を管理し、割当端末数を自動集計。
* **顧問先提出用「労務セキュリティ診断報告書」**:
  * 対象企業名・社労士法人名を入力し、A4用紙（印刷・PDF保存）としてそのまま顧問先へ納品可能なレポート生成。
* **完全クライアントサイド（DB不要）**:
  * 外部サーバーへデータを一切送信しないため、顧客情報・機密情報を安全に取り扱えます。
  * お使いのブラウザ（LocalStorage）に安全に保存・再開可能。
* **CSVインポート / エクスポート**:
  * 端末台帳・社員名簿・リスク検出結果をCSV形式で入出力可能。

## 🚀 Cloudflare Pages での公開手順

本ツールは静的HTML/JavaScriptで完結しているため、Cloudflare Pages にわずか数ステップで無料公開できます。

1. **GitHubリポジトリを作成**:
   ```bash
   git add .
   git commit -m "Initial commit: 社労士向け 端末台帳＆労務セキュリティチェッカー v1.0.0"
   git remote add origin https://github.com/<YOUR_ACCOUNT>/<REPO_NAME>.git
   git branch -M main
   git push -u origin main
   ```
2. **Cloudflare ダッシュボードにログイン**:
   - [Workers & Pages] > [Create application] > [Pages] > [Connect to Git] を選択。
3. **リポジトリを選択**:
   - 上記で作成したGitHubリポジトリを選択。
4. **ビルド設定**:
   - フレームワーク プリセット: `None`
   - ビルドコマンド: 空欄（なし）
   - ビルド出力ディレクトリ: `/`（ルートディレクトリ）
5. **[Save and Deploy] をクリック**:
   - 数十秒で専用のURL（`https://<project-name>.pages.dev`）が発行され、Web上でアクセス可能になります。
